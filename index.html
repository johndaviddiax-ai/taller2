Bienvenido al Taller 2

En este taller aprenderemos sobre diferentes etiquetas y estructuras de HTML y CSS, incluyendo Grid, Audio, Video y Formularios de Contacto. A través de ejemplos prácticos, conocerás cómo utilizarlas para crear páginas web más organizadas, interactivas y atractivas.


Modelo de caja(box model)

El modelo de caja define como se comportan los elementos HTML. Consiste en margen (margin) bordes (border), relleno (padding), y el contenido (content).
